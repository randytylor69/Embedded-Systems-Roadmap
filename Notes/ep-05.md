> This episode acts as a continuation from the last episode, where we use the C preprocessor and the *volatile* keyword to improve our blinking program.

Our previous code is bare bone and not intuitive for a human reader; for example, it does not show the offset calculations. We can make it more readable & maintainable by adding C preprocessors:

```C
#define RCGCGPIO    *((unsigned int *)0x400FE608U)

#define GPIOF_BASE  0x40025000U
#define GPIOF_DIR   *((unsigned int *)(GPIOF_BASE + 0x400U))
#define GPIOF_DEN   *((unsigned int *)(GPIOF_BASE + 0x51CU))
#define GPIOF_DATA  *((unsigned int *)(GPIOF_BASE + 0x3FCU))

int main(){
	RCGCGPIO  = 0x20U; /* enable clock for GPIOF */
	GPIOF_DIR = 0x0EU; /* set pins 1,2,3 as outputs */
	GPIOF_DEN = 0x0EU;
	
	while(1){
		*((unsigned int *)0x400253FCU) = 0x02U;
		*((unsigned int *)0x400253FCU) = 0x00U;
	}
	
	return 0;
}
```
