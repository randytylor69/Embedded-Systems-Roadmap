> C structs and the Common Microcontroller Software Interface Standard

So far, we're controlling board peripherals directly via register addresses. For example:

```c
SYSCTL_RCGCGPIO_R |= (1U << 5);  // turn on bit 5
```

It'll be more organized to design a C struct whose members correspond to certain registers. Luckily, such structs are already defined inside `tm4c_cmsis.h` by the microcontroller vendor. It surely contains a struct for:

- `SYSCTL`

- `GPIOF`

So instead of hard coding the register addresses, we can use the provided structs instead:

```c
#include <tm4c_cmsis.h>

SYSCTL->RCGC2 |= (1U << 5);
GPIOF->DIR /*...*/
GPIOF->DEN /*...*/

```
