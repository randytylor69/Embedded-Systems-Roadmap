> This lecture provides answers to some tricky answers regarding data types in C

The C99 standard introduces `<stdint.h>` that provides many useful data types, such as `uint32_t` or `int16_t`. The number indicates their size in bits. 

Inevitably they'll be mixed in functions & expressions, and we have to perform type casting.

- Good news: C implicity converts them!

- Bad news: the conversion rules are very conterintuitive
